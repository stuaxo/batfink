    What the machine is doing
    
    
    
      There is no firmware here. The program pages both ROMs out and writes straight to the hardware,
      which is how demos were actually written.
    
    
    
    
      
    &7F00
    Gate Array. Picks an ink, sets its colour, and selects the screen mode.
    
      
    &F500
    PPI port B. Bit 0 goes high during the vertical sync pulse, which is how the program stays at 50Hz.
    
      
    &0038
    Interrupt vector. The CPC interrupts six times a frame, every 52 scanlines.
    
      
    &C000
    Screen memory. 16K, and famously not linear: eight interleaved blocks of &800, one per raster line within a character row.
    
    
    

    
    Sharing and saving
    
    
    
      Copy share link puts the whole listing, compressed, in the page URL. No account, no server:
      the link is the program. Save… keeps named revisions in this browser.
    
    

    
    Downloads
    
    
    
      
    .sna
    Version 2 snapshot, captured at the entry point with both ROMs paged out. Loads on any CPC emulator. Best for checking a raster split lands in the same place.
    
      
    .bin
    Raw assembled bytes, optionally with a 128-byte AMSDOS header (type, load and entry address, checksum).
    
      
    .dsk
    Standard 40-track DATA disc holding the AMSDOS-headered binary. There is no autoboot on a DATA disc: mount it and type RUN"NAME".
    
      
    .cdt
    Tape image in the firmware cassette format. RUN"" to load the first file.
    
    
    

    
    Checking it on another emulator
    
    
    
      Drop a snapshot on Andre Weissflog's floooh.github.io/tiny8bit/cpc.html (the
      cpc-ui build has a disassembler and memory viewer), cpcbox.com, or a
      desktop emulator such as WinAPE. Two things will not match: there is no sound, so PSG registers
      read back zero; and timing is charged per instruction, not per machine cycle, so a split placed
      to the exact T-state may drift a few cycles against a reference.
    
    

    
    The assembler
    
    
    
      Labels, org, equ, db, dw, ds,
      align, the full base instruction set, CB shifts and bit operations,
      ED block moves, and the IX / IY index registers.
      Numbers: &FF, #FF, 0xFF, %1010 or decimal.
      Execution starts at the label start.
